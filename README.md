# Daftar

**Daftar** (دفتر, "logbook") is a bilingual coach booking and workout-logging web app. One coach (who is
also the admin) and many clients: clients book sessions, follow the program the coach writes (or write
their own) and log every set. Persian (RTL, Jalali calendar) is the default language; English is a full
second language.

Design brief: [`docs/DESIGN.md`](docs/DESIGN.md) · Architecture and contracts: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

Stack: Next.js 15.5 (App Router, React 19, Server Actions) · TypeScript strict · PostgreSQL 16 + Prisma 6.19 ·
next-intl 4 · Tailwind CSS 4 · zod 4 · own auth (phone + password, argon2id, DB sessions) · Vitest · Playwright.

## Setup

Requirements: Node 22 (>= 22.12), npm, PostgreSQL 16.

```bash
# 1. a database (any role/db you like; this matches .env.example)
createdb daftar_dev            # or: CREATE DATABASE daftar_dev;

# 2. environment
cp .env.example .env           # DATABASE_URL=postgresql://daftar:daftar@localhost:5432/daftar_dev

# 3. install (also runs `prisma generate`)
npm install

# 4. schema + dev data
npm run db:migrate             # prisma migrate dev (applies prisma/migrations, incl. the booking_active_slot index)
npm run db:seed                # coach, 6 clients, 1,324 exercises, programs, workout history, bookings

# 5. run
npm run dev                    # http://localhost:3000  ->  redirects to /fa
```

`npm run db:reset` drops the database contents, re-applies every migration and re-seeds. Prisma refuses to run
`migrate reset` from an AI agent session unless the human gives explicit consent; run it yourself in a terminal.

### Seeded credentials (development only, change them anywhere real)

| Who | Phone | Password |
|---|---|---|
| Coach / admin | `09120000000` | `coach-pass-1234` |
| Clients 1 to 6 | `09120000001` … `09120000006` | `client-pass-1234` |

Phone numbers may be typed with Persian or Arabic digits (`۰۹۱۲۰۰۰۰۰۰۰`), spaces or dashes; they are stored as
E.164 (`+989120000000`). The seed is idempotent: running `npm run db:seed` again rebuilds the data that
depends on "now" (availability, time off, programs, workouts, bookings) without duplicating anything.

## What is in the box (Phase 1)

- `src/lib`: `db`, `auth` + `session` + `password` (argon2id, DB sessions), `rate-limit`, `otp` (interface only),
  `settings`, `digits`, `phone`, `format`, `time` (coach wall clock <-> UTC, Saturday/Monday weeks, Jalali months),
  `plates`, `validation`, `redirects`.
- `src/components/ui`: Button, Field, Input, NumberInput, PhoneInput, PasswordInput, Select, Textarea, Sheet, Dialog,
  Tabs, Stamp, Tally, SectionLabel, EmptyState, Avatar, LocaleSwitch, ThemeToggle, DirIcon, Toast, Flash, BarbellDiagram.
- App shells for `/[locale]/app` (tab bar + rail) and `/[locale]/coach` (rail + mobile menu sheet), placeholder pages
  for every route in the route map, and fully built login/register.
- `/[locale]/styleguide` (development only, 404 in production): every primitive in both themes.

## Notes

- **Auth**: the middleware only checks that the `daftar_session` cookie exists (UX redirect to `/login?next=`). Every
  page and server action re-checks with `requireUser()` / `requireCoach()`. A non-secret `daftar_role` cookie lets the
  middleware bounce a CLIENT from `/coach` to `/app`; it is advisory only and never trusted for authorization.
- **Rate limiting** (5 failed logins per phone per 15 minutes) is an in-memory map: correct for a single instance,
  resets on restart. Use a shared store before running more than one instance.
- **Theme**: follows `prefers-color-scheme`; the toggle stores `theme=light|dark` in a cookie that the server reads.
- **Locale**: always-prefixed routes (`/fa/...`, `/en/...`). `/` goes to `/fa`; the language is never guessed from the browser.
- **Time**: instants are stored in UTC; wall-clock logic runs in the coach timezone (`CoachSettings.timezone`, default `Asia/Tehran`).
